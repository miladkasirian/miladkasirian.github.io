Guide: How to Merge and Reduce PDF File Size

FIN 322 - Financial Institutions & Markets

You may face challenges when trying to combine (merge) multiple PDF files into a single file, or when your PDF files have excessively large file sizes.

There are many solutions available, but I will provide you with two free options. You can search for other methods if needed.

Approach 1: Online Tools (Quick & Easy)

For Merging PDFs

Use this online website for merging PDFs:

https://www.ilovepdf.com/merge_pdf

For Reducing PDF Size

Use this online website for compressing PDFs:

https://www.ilovepdf.com/compress_pdf

Note: I don't strongly recommend the compression tool because it reduces the quality significantly, but it is still a good option if you need very small file sizes.

Approach 2: Offline Solution Using Ghostscript (Recommended)

This approach uses Ghostscript, a free and powerful PDF processing software that works on both Windows and Mac OS.

Why Use Ghostscript?

  • Completely free and open-source
  • Works offline (no internet required)
  • No file size limits
  • Better control over quality
  • Privacy-friendly (files stay on your computer)
  • Can merge AND compress in one step

Windows Instructions

Step 1: Installation

Download and install Ghostscript from:

https://www.ghostscript.com/download/gsdnld.html

Important: Choose the AGPL Release - Windows 64-bit version

Tip: I put commands for Win 64-bit. If your Windows is 32-bit, change the 64 to 32 in the command line (e.g., gswin32c instead of gswin64c). How to know your Windows's BIT? Right-click on the Start menu and click System, you can see the System type there.

Step 2: Reducing PDF File Size

Let's assume your PDF file is on your Desktop and named example.pdf.

  1. Open Command Prompt from the Start menu (search for "cmd")
  2. Edit the file names in the box below if needed, then click Copy:
Command (editable - change file names as needed)

How to customize:

  • Change example.pdf to your file name
  • Change example_compressed.pdf to your desired output name
  • If your file is in a different location, change cd Desktop to the correct path (e.g., cd /d "C:\Documents")

Quality Settings

You can adjust the quality by changing /printer to one of these options:

Setting Quality DPI File Size Best For
/screen Lowest 72 Smallest Screen viewing only
/ebook Moderate 150 Medium General use
/printer High 300 Larger Printing, submission
/prepress Highest 300 Largest Professional printing

My recommendation: Use /printer for the best balance between quality and file size.

Step 3: Merging PDF Files

Let's assume you have 3 PDF files on your Desktop: example.pdf, example2.pdf, and example3.pdf.

  1. Open Command Prompt
  2. Edit the file names in the box below if needed, then click Copy:
Command (editable - change file names as needed)

How to customize:

  • Change example.pdf example2.pdf example3.pdf to your file names
  • List files in the order you want them merged
  • Change merged.pdf to your desired output name
  • You can merge as many files as you want by listing them all
Bonus: Ghostscript automatically compresses the merged PDF to print quality (300 DPI), so you get both merging and size reduction in one command!
